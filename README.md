# balanced-grill-to-doc

一个"拷问想法 → 输出文档"的 Skill。核心不是问得多，是**知道什么时候不该再问**，以及**问完之后怎么说人话**。

## 它和你直接跟 AI 说"拷问我"有什么不同

| | 普通对话 | 这个 Skill |
|---|---|---|
| 追问节奏 | 连续问 / 问到烦 / 问两下就放过 | 一次一个，够判断就停 |
| 判断立场 | 看模型当天的发挥：要么狂夸要么狂泼冷水 | 固定姿态：肯定你想解决什么，质疑它凭什么成立 |
| 输出结构 | 每次都不一样，得自己再整理 | 固定文档结构，拿过来就能改 |
| 信息留存 | 聊完就散 | 全程记台账，最后汇总进文档 |

## 触发

直接说这些话就会命中：

- "拷问我的想法" / "挑战一下这个方案"
- "帮我看看这个靠不靠谱" / "不要盲目迎合我"
- "追问到你能判断为止"
- "边聊边记，最后给我总结成文档"
- `grill me` / `stress-test this decision`

## 流程

1. **接住**：复述你在决定什么 —— 你确认"他听懂了"
2. **追问**：一次一个，每轮之后自己判断是否够了 —— 够了就停
3. **确认格式**：是否需要，如需要，Markdown 还是 Word
4. **出文档**：一份，便捷可改

## 输出的文档长这样

```markdown
# [想法 / 决策名称]
> 一句话结论：[支持 / 有条件支持 / 不建议 / 先验证 X]

## 1. 我的理解
## 2. 关键假设（来源 / 不成立会怎样）
## 3. 风险与边界（机制 / 触发信号 / 应对）
## 4. 我的建议（带条件、可执行）
## 5. 待确认 / 遗留问题
## 6. 追问记录（简版）
```

## 安装

把 `SKILL.md` 放到你 Agent 的 skills 目录下即可：

- Claude Code：`~/.claude/skills/balanced-grill-to-doc/SKILL.md`（你配了 `CLAUDE_CONFIG_DIR` 就放对应目录）
- WorkBuddy 项目级：`{项目}/.workbuddy/skills/balanced-grill-to-doc/SKILL.md`
- WorkBuddy 用户级：`~/.workbuddy/skills/balanced-grill-to-doc/SKILL.md`

## 可调的地方

| 想调什么 | 改哪里 |
|---|---|
| 问得更多 / 更少 | `phase 2.1` 的三问自检，或 `2.2` 的停止启发式数量 |
| 更犀利 / 更温和 | "核心姿态"里的语气准则和话术对照表 |
| 文档章节 | Phase 4 的文档模板 |
| 触发词 | frontmatter 的 `description` |
